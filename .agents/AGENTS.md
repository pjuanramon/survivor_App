# Survivor App — Workspace Directives & Core Philosophy

## 🚀 Core Vision: Millionaire Scale & Product Excellence
- Everything built in this project must be designed for **massive scalability, viral engagement, premium UI/UX, and commercial monetization**.
- Architecture, database schema, state management, and user flows must be modular, performant, and ready for thousands of leagues and millions of active users.
- Design aesthetics must feel state-of-the-art, high-converting, and top-tier (dark mode, neon accents, crisp visual feedback).

## 📈 Estrategia de Crecimiento, Viralidad y Monetización (Hoja de Ruta a Agosto)
- **Filosofía Competitiva (CERO Pay-to-Win)**: Pagar NUNCA debe dar ventajas injustas a un jugador sobre otro dentro de la misma liga. Todas las ligas se juegan en igualdad de condiciones.
- **Modelo de Monetización (Objetivo Agosto / Nueva Temporada)**:
  1. **Modo Clásico (Gratis con Anuncios)**: El Survivor tradicional (1 pick por jornada, sin repetir equipo, VIVO/RIP). Monetizado mediante publicidad integrada y patrocinios B2B.
  2. **Suscripción / Pase PRO y "Modo Cartas" (Sin Anuncios + Nuevos Modos de Juego)**: Pagar elimina los anuncios y desbloquea modos de juego avanzados para toda la liga, especialmente el **Modo Cartas / Táctico** (cartas estilo Kings League: *Bloqueo/Veto de equipo a un rival*, *Kamikaze*, *Robo/Espejo*, *Maleficio*) y reglas personalizadas (2 vidas, mercado de invierno, sprints).
- **Motores de Crecimiento Orgánico (Prioridad de Desarrollo Actual → Verano)**:
  1. **Multi-Ligas Privadas (WhatsApp) + Ligas Masivas de Creadores (TikTok/Streamers)**: La arquitectura debe soportar tanto ligas privadas de 10-20 amigos como ligas públicas masivas (miles de seguidores de un creador/influencer) con links de invitación directos.
  2. **Rotación Continua (Sprints / Reseteo de Rondas)**: Cuando una liga termina (queda 1 superviviente), debe poder reiniciarse una nueva ronda/edición fácilmente para que nadie quede inactivo durante meses.
  3. **Compartibles Virales (Tarjetas RIP / Resumen de la Carnicería)**: Generar resúmenes visuales listos para compartir en WhatsApp, TikTok e Instagram Stories al finalizar cada jornada con el link de invitación integrado.
  4. **Viral Gating (Desbloqueo por Invitación)**: Antes de activar pagos en agosto, usar la invitación de amigos activos verificados como moneda para desbloquear funciones especiales, insignias o avances del Modo Cartas.

## ⚽ Results Processing Protocol
- **Matchday Results**: Follow Option A (manual/instructed updates via chat).
- When the user requests *"Actualiza los resultados de la Jornada X"*, perform authoritative research on final match scores, calculate point and goal difference updates, update survivor status (VIVO / RIP), and advance the active matchday.
