# Survivor App — Workspace Directives & Core Philosophy

## 🚀 Core Vision: Millionaire Scale & Product Excellence
- Everything built in this project must be designed for **massive scalability, viral engagement, premium UI/UX, and commercial monetization**.
- Architecture, database schema, state management, and user flows must be modular, performant, and ready for thousands of leagues and millions of active users.
- Design aesthetics must feel state-of-the-art, high-converting, and top-tier (dark mode, neon accents, crisp visual feedback).

## ⚽ Results Processing Protocol
- **Matchday Results**: Follow Option A (manual/instructed updates via chat).
- When the user requests *"Actualiza los resultados de la Jornada X"*, perform authoritative research on final match scores, calculate point and goal difference updates, update survivor status (VIVO / RIP), and advance the active matchday.
